## Project context

A Real Estate Appraisal course project investigated residential prices in Beijing’s Dongcheng District using a hedonic price model.

## My contribution

- Web-scraped residential property listings.
- Retrieved property coordinates and points of interest through the Gaode Map API.
- Transformed coordinates, imported the datasets into ArcGIS and created spatial data.
- Built locational variables using spatial analysis, cleaned the data and analysed relationships between property attributes, location and price.

## Methods & tools

The workflow combined web data collection, coordinate transformation, GIS analysis and quantitative modelling. No API keys or source datasets are published with this portfolio.
